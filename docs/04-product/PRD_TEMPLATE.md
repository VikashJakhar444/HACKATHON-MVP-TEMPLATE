## 7. Non-Functional Requirements
- **Performance**: Instantaneous or sub-second response times for primary user actions.
- **Reliability**: Zero unhandled exceptions or fatal application crashes during standard workflows.
- **Security & Privacy**: No hardcoded API keys; sanitize all user inputs; safe client storage.
- **Accessibility & UX**: Clean typography, high contrast, intuitive button affordances, clear error feedback.
- **Responsiveness**: Smooth layout adaptation across desktop and tablet viewports.
